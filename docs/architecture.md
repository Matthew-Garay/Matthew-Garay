# Arquitectura y Decisiones de Diseño

## Visión general

Este repositorio es el Profile README de Matthew Garay Pérez. Sirve como tarjeta de presentación profesional y portafolio de proyectos.

## Decisiones de arquitectura (ADR)

### ADR-001: Estilo profesional sin emojis

**Estado:** Aceptado  
**Contexto:** El perfil debía transmitir profesionalismo y claridad para reclutadores y colaboradores técnicos.  
**Decisión:** Eliminar emojis del README y usar badges estáticos de shields.io con enlaces funcionales.  
**Consecuencias:** El perfil se ve más sobrio y enfocado en el contenido técnico.

### ADR-002: Repositorio privado para el perfil

**Estado:** Aceptado  
**Contexto:** Control de visibilidad del contenido del perfil personal.  
**Decisión:** Mantener el repositorio del perfil como privado hasta que se decida hacerlo público.  
**Consecuencias:** El README del perfil no se muestra públicamente en GitHub hasta cambiar la visibilidad.
